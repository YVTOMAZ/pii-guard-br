# Suporte

## Onde pedir ajuda

- **Issues:** https://github.com/YVTOMAZ/pii-guard-br/issues para bugs e sugestões.
- **Documentação:** `docs/ambiente.md`, `docs/uso.md`, `docs/configuracao.md`,
  `docs/limites.md`.
- **Segurança:** veja `SECURITY.md` (não abrir issue pública).

## Antes de abrir uma issue

1. Verifique se o problema já foi reportado.
2. Execute `make test` e anexe o resultado (sem dados reais).
3. Use apenas dados sintéticos em exemplos.

## Escopo de suporte

Este é um MVP focado em configuração segura e validação reproduzível em
Linux/Bash. Suporte a outros sistemas operacionais ou provedores não está
incluído no escopo atual.
